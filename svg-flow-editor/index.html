속성 편집 · 전체 도면

실제 도면 폭에 맞춰 제목을 중앙으로 놓습니다. 내부 여백 8px ≈ 2mm(96dpi 기준).
제목·부제는 각각 투명한 박스입니다. 글자를 드래그해 이동하고 선택 테두리의 조절점으로 크기를 변경합니다. 저장할 때 테두리는 제거됩니다.
박스를 드래그하면 연결선이 자동으로 따라갑니다. 판단 마름모는 꼭짓점에서만 분기합니다.
마름모에서는 도형 꼭짓점을 출발점으로 계산합니다. 반대쪽 노드를 이동해도 자동 재계산됩니다.
불러온 외부 SVG는 원본 요소 선택·이동·문자 편집·재저장을 지원합니다. 자동 연결 재배치는 편집기 고유 JSON 도면에서 지원합니다.

편집 방법

① 도형을 눌러 선택 → ② 드래그하거나 오른쪽 숫자 수정 → ③ SVG 저장. 여러 도형 선택은 Shift+클릭. 연결선 추가는 시작 도형과 끝 도형을 차례로 클릭합니다.

단축키: Delete 삭제 · Ctrl+Z 취소 · Ctrl+Shift+Z 복원 · 방향키 5px 이동.
